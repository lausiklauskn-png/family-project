🎁 Mycel-Geschenkbox

Alle SBKIM-Werkzeuge zum Herunterladen & Installieren

Die Geschenkbox macht aus deiner Seite einen vollen Mycel-Knoten: Verbinden + Vertrauens-Siegel + Schutz-Lampen + Andock-Wizard + Schlüssel-Safe + Suche + Sprache/Bild-Eingabe, alles fertig zum Auspacken. Weiter unten: vier Wege, sie in deine App zu holen, nach Können sortiert.

📦 Was in der Box ist

Verbinden-Kern: eigene Identität (Ed25519), Bedeutungs-Suche, Handshake, gemeinsamer Raum, mit Kartenechtheit & Flut-Schutz.
Vertrauen: SBKIM-Siegel (Bronze→Gold), Status-Lampen, Fremdzugriff-Wächter.
Werkzeuge: Andock-Wizard, verschlüsselter Schlüssel-Safe, Such-Widget, Spracheingabe, Bild→Text (OCR).

Nur verbinden wollen? Es gibt auch die schlanke „Verbinden"-Box (nur die Kern-Bausteine). Eine fertige App zum Installieren ist das Such-Tool.

Schlanke Verbinden-Box ↗ Such-Tool (App) ↗
Für alle gilt zuerst: Du baust die Box in dein eigenes Repo ein, in die App, die dir gehört. Hast du nur eine lose Datei ohne Repo, ist ein eigenes Repo anzulegen der erste Schritt (das kann dir eine KI abnehmen). Gerät egal: PC und Tablet gehen beide. Nichts kostet etwas, kein Konto zum bloßen Ansehen.

🤖 Meine KI baut es ein

🟢 Für Einsteiger, am einfachsten (die KI macht die Arbeit)
Deine Voraussetzung: eine kleine App in einem eigenen Repo und einen KI-Chat bedienen können. Programmieren nicht nötig.
Technisch: eine KI, die an dein Repo kommt (z. B. Claude Code / KI mit GitHub-Anbindung), oder eine KI, die dir die Schritte hinlegt.
Am Ende: die Box vollständig eingebaut, du hast nur beauftragt.

Diesen Text deiner KI geben:

Bitte baue die SBKIM-Voll-Box in mein Repo ein: Kopiere alle Dateien aus
https://github.com/lausiklauskn-png/Sage-Protokol/tree/main/sbkim-bundle-voll
byte-genau in meinen Ordner sbkim-bundle-voll/ und trage die <script>-Zeilen
aus deren README in meine index.html ein (Reihenfolge: 17 vor 15 vor 16).
Ändere die Modul-Dateien NICHT. Alles bleibt fail-soft und offline.
Box ansehen ↗

🍴 Als Vorlage / neu anfangen

🟢 Für Neustarter, ein Klick, aber neues Repo
Deine Voraussetzung: du hast noch KEINE App und willst mit fertigem Grundgerüst starten.
Technisch: GitHub-Konto · ein Klick · kein Terminal.
Am Ende: ein NEUES Repo mit Box drin. Nicht für „ich habe schon eine App". Das würde ein zweites, leeres Repo erzeugen.

in Vorbereitung Das Ein-Klick-Template wird als nächstes gebaut.

⬇️ Als ZIP herunterladen & hochladen

🟡 Ohne KI & ohne Terminal, dafür etwas Handarbeit
Deine Voraussetzung: eine App in einem eigenen Repo; du magst Dateien laden/hochladen und in GitHub klicken.
Technisch: GitHub-Konto (deins) · dein Repo · Browser (PC oder Tablet) · kein Terminal, kein Node.
So läuft's: ZIP laden → Ordner sbkim-bundle-voll heraussuchen → in deinem Repo „Add file → Upload files".
Am Ende: die Box im Repo; die Script-Zeilen trägst du danach ein (README oder KI).
Sage als ZIP laden ↓ Was drin ist ↗

Hinweis: der Browser lädt am Tablet oft nur Datei-für-Datei. Ordnerstruktur (modules/…) beibehalten. Das ist der mühsame Teil; wer eine KI hat, nimmt lieber den obersten Weg.

⚡ Mit einem Befehl (Installer)

🔴 Für Versierte, dafür am schnellsten (ein Befehl)
Deine Voraussetzung: du traust dir einen Terminal-Befehl zu.
Technisch: Node installiert · Terminal (PC oder Termux) · dein Repo lokal geklont · GitHub-Konto zum Hochladen.
Am Ende: ein Befehl → Box drin + Script-Zeilen automatisch eingetragen.

Diese Befehle im Ordner deines Repos:

curl -O https://raw.githubusercontent.com/lausiklauskn-png/Sage-Protokol/main/sbkim-bundle-voll/install.mjs
node install.mjs --fetch --target .

Holt die Box aus dem Netz und verdrahtet deine index.html. Ein Befehl, plattformübergreifend, ohne npm. Hast du die Box schon lokal (Weg oben), genügt: node sbkim-bundle-voll/install.mjs. Mit --dry siehst du vorher, was passiert.

Schnell-Entscheidung: Kleine App im Repo + kaum Programmier-Kenntnisse → „Meine KI baut es ein" (oben). Terminal-fit + schnell → Installer. Bei null anfangen → Vorlage.
